# Archived Path Studio

Path Studio was removed from the public Browser Tools website on 2026-09-16
because it no longer matched the site's intended direction.

The implementation is preserved here for possible future reuse:

- `templates/path_studio.html`
- `static/css/path-studio.css`
- `static/js/path-studio.js`

These files are intentionally outside the Flask template and static folders,
so the application does not publish or link to the feature.
